DICTIONARY SHOWCASE PACK

Contents:
- README.md: polished project README with clickable live links, Mermaid architecture diagram, collapsible screenshot gallery, technology explanations, local setup, and a 90-second demo script.
- assets/screenshots/: the six screenshots supplied by the project owner.

How to publish:
1. Download and extract dictionary-showcase-pack.zip.
2. In your local dictionary-ai repository, replace README.md with this README.md.
3. Copy the assets/ folder into the repository root so paths like assets/screenshots/home.jpg work.
4. Commit and push the README and assets to GitHub.
5. Open the repository page to verify the screenshots and Mermaid diagram render.
6. Record a short screen walkthrough and replace the demo-video placeholder URL when ready.

Security reminder:
Do not upload .env, API keys, workspace databases, or private user datasets.
